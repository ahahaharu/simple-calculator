## 2. How to Run the App

Clone the repository:
```
git clone https://github.com/ahahaharu/simple-calculator.git
```

### To start the development server:

1. Install dependencies:
```
npm install
```
2. Start the server:
```
npm start
```

### To build project:

1. Install dependencies:
```
npm install
```

2. Run the build command:
```
npm run build
```
